Build and run (Zed: run the "Build & Run" task, or from any terminal):

    build.bat run

Build only:

    build.bat

build.bat auto-loads the Visual Studio (MSVC) environment, configures the
Ninja "ninja-debug" preset into ./build on first run, builds, and the exe is
at build\OpenGL.exe.

Manual equivalent (must be run from an "x64 Native Tools Command Prompt for
VS 2022" so cl.exe is on PATH):

    cmake --preset ninja-debug
    cmake --build --preset ninja-debug
    build\OpenGL.exe
